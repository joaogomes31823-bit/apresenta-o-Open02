# Starbucks · Planejamento Estratégico

Apresentação acadêmica independente, por Alexandre Gomes.

## Publicação no Render

Tipo: Static Site. Branch: main. Build command: `test -f dist/index.html`. Publish directory: `dist`.

Sem dependências, banco de dados ou configuração de segredos. Os 12 capítulos, a navegação, a leitura contínua e o modo de apresentação funcionam no navegador. As fontes e os critérios do estudo estão no capítulo final.

## Verificação local

`node --check dist/app.js`

A fotografia é creditada à Starbucks Stories. O estudo não tem vínculo institucional com a Starbucks.
